Secure postMessage with Origin Validation

This page demonstrates a message event listener that validates event.origin and renders received content safely via textContent.

How it behaves

  1. Open this file in your browser (served via any origin).
  2. Messages are only accepted from the same origin as this page; messages from any other origin are ignored.
  3. Accepted message content is rendered as plain text via textContent, so embedded HTML/JS is never executed.
